# Akash More — Portfolio

A responsive React + Tailwind CSS portfolio inspired by the supplied monochrome ID-card / profile-card reference.

## Stack
- React
- Vite
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Optional profile photo
The current hero uses an `AM` monogram so the project works immediately. If you want the reference's photo-card look, add your own photo as:

`public/profile.jpg`

Then replace the `AM` block in `src/App.jsx` with an `<img src="/profile.jpg" ... />`.

## Resume
Put your resume PDF at:

`public/Akash-More-Resume.pdf`

The Resume button is already wired to that filename.
